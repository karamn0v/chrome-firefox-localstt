# GigaAM STT на DXP4800+

Локальная русская диктовка: модель **GigaAM v3 e2e-rnnt** крутится в Docker на NAS, Chrome-расширение пишет голос на сервер и вставляет текст в активное поле.

На **Ugreen DXP4800+** (Intel Pentium Gold 8505: 1P+4E, 6 потоков, 16 ГБ DDR5) инференс идёт на CPU, INT8. Встроенный UHD / Quick Sync для этой модели не используется: у `gigastt` нет OpenVINO-пути под Intel GPU. 8505 заметно быстрее N100, короткие фразы должны уходить за секунду-две после стопа.

## Как это устроено

1. `gigastt` в Docker слушает `http://<IP-NAS>:9876`
2. Расширение пишет с микрофона WebM/Opus
3. NAS возвращает уже пунктуацию и нормализацию
4. Текст вставляется в поле, где стоит **текстовый курсор**. Если вставить нельзя (чужое приложение, `chrome://`, PDF) — текст копируется, вставляете `Ctrl+V`

Chrome **не умеет** писать в Word, Telegram и другие окна Windows. Для них как раз буфер обмена.

## 1. Docker на UGOS

На NAS должен быть **Container Manager**. Первый запуск качает ~225 МБ весов — нужен выход в интернет (GitHub).

1. Скопируйте `docker-compose.yml` на NAS или вставьте его в **Compose → Create**
2. Запустите стек `gigastt`
3. Подождите, пока контейнер станет healthy. Проверка с ПК:

```bash
curl http://IP-NAS:9876/health
curl http://IP-NAS:9876/ready
```

`/ready` должен ответить `{"status":"ready",...}`. Пока качается модель, `/health` уже живой, `/ready` — 503.

Порт **9876 не пробрасывайте** в интернет. Это домашняя LAN-служба без пароля.

Контейнер может занять до 8 ГБ из 16 (`mem_limit` — потолок, не резерв). Реально `gigastt` ест около 0.5–1 ГБ RSS. CPU: 5 из 6 потоков, `pool-size 1`, один поток оставлен UGOS.

## 2. Расширение Chrome

1. `chrome://extensions` → режим разработчика
2. **Загрузить распакованное** → папка `extension`
3. Нажмите на иконку → шестерёнка → URL `http://192.168.88.176:9876` → **Проверить связь**
4. Один раз откройте страницу разрешения микрофона, если Chrome спросит

Готовый архив: `dist/gigaam-stt.zip` (сборка: `powershell -File scripts/pack.ps1`). Для Chrome Web Store загружают этот zip. Обычный Chrome больше не ставит `.crx` перетаскиванием — для себя удобнее распакованная папка.

## 3. Firefox

1. `about:debugging#/runtime/this-firefox`
2. **Load Temporary Add-on…** / **Временный дополнение**
3. Укажите `extension/manifest.firefox.json` (или `dist/gigaam-stt-firefox.zip`)
4. Шестерёнка → `http://192.168.88.176:9876` → **Проверить связь**. Разрешите микрофон, когда Firefox спросит.

В Firefox расширение не делает `fetch` на NAS (это даёт `NetworkError`). Открывается служебная вкладка **GigaAM NAS** с iframe на `/health` — тот же способ, которым JSON открывается в обычной вкладке. Вкладку можно свернуть, не закрывайте её во время диктовки.

Если включён прокси (системный, SOCKS или FoxyProxy), исключите NAS:

- Настройки → Параметры сети → **Не использовать прокси для:** `192.168.88.176, 192.168.88.0/24, localhost, 127.0.0.1`
- или `about:config` → `network.proxy.no_proxies_on`
- в FoxyProxy — правило DIRECT для `192.168.88.176`

Временное дополнение снимается при перезапуске Firefox. Постоянно без подписи AMO можно только в Developer Edition / Nightly: `about:config` → `xpinstall.signatures.required` = `false`, затем «Install Add-on From File».

Диктовка та же: удерживайте `Alt+Z` / `Alt+Я` на обычной http/https-вкладке.

Диктовка:

- клик по кнопке в popup **или**
- удерживайте `Alt+Z` / `Alt+Я`, отпустите чтобы распознать
- максимум 90 секунд на одну фразу

Поставьте курсор в поле ввода **до** отпускания клавиш.

После обновления расширения обновите вкладку. Если в `chrome://extensions/shortcuts` ещё висит Alt+Z — удалите его, иначе Chrome снова перехватит клавишу и стоп не сработает. Если оверлей NVIDIA перехватывает Alt+Z, отключите его в GeForce Experience.

## 4. Ожидания по качеству

- Русский, с пунктуацией и нормализацией
- Английские вставки в русской речи обычно ок, полноценный английский — нет
- Распознаёт пачку после стопа, не слово за словом. На 8505 короткая фраза обычно быстрее realtime; минута речи всё ещё будет считаться заметно дольше записи
